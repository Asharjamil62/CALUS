# CALUS Calculator

A simple browser-based calculator built with HTML, CSS, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Percentage conversion
- Clear and delete controls
- Decimal input
- Divide-by-zero handling

## Run locally
Open `index.html` in a browser. The stylesheet and JavaScript are loaded from the same folder.

## Project files
- `index.html` — calculator structure
- `style.css` — layout and visual styling
- `app.js` — calculator interaction and arithmetic logic
